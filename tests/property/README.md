# Property tests

Этот каталог зарезервирован для будущих property tests.

Кандидаты для генерации:

- slotted page operations;
- insert/delete marker/compact;
- checksum validation;
- catalog encode/decode;
- heap insert/full scan;
- B+Tree insert/split/lookup;
- SQL row encode/decode.

Главная цель — проверять инварианты на множестве случайных последовательностей операций, а не только на одном ручном примере.
